# 倍朗达工业自动化官网多语言 SEO/GEO 设计

## 目标

将现有静态官网重构为可部署到 IIS 的现代化工业自动化官网，首期支持中文、英文、俄语，并建立可被传统搜索引擎和生成式搜索理解的内容结构。

## 技术边界

- 采用静态 HTML/CSS/JavaScript，兼容现有 IIS/ASP.NET 主机环境。
- 语言 URL 使用 `/zh-cn/`、`/en/`、`/ru/`，不依赖查询参数或翻译插件。
- 首期交付首页、解决方案、产品、案例、技术资料、关于我们、联系/询价入口的内容框架。
- 当前只创建新站原型与部署包，不直接修改线上 balenda.cn，也不处理服务器入侵清理。

## 页面与内容模型

导航由以下一级栏目组成：解决方案、产品中心、项目案例、技术资料、服务支持、关于倍朗达、新闻资讯、联系我们。

产品内容统一包含：产品名称、适用行业、解决问题、核心参数、系统集成方式、应用案例、资料下载、咨询 CTA。

解决方案内容统一包含：行业痛点、系统组成、工作流程、交付范围、可量化收益、常见问题和相关产品。

## 多语言行为

1. 页面路径决定初始语言。
2. 用户点击语言切换后，保持当前页面语义位置。
3. 手动选择写入 `localStorage`，后续访问优先使用该选择。
4. 没有手动选择时，根据浏览器语言选择中文、英文或俄语；无法匹配时使用中文。
5. 每个页面为三种语言输出独立可抓取 HTML，不把核心内容只放在客户端 JavaScript 中。
6. 每个页面输出互相对应的 `hreflang`、自引用 `canonical` 和 `x-default`。

## SEO/GEO 设计

- 使用语义化 HTML、唯一 H1、清晰 H2/H3、BreadcrumbList。
- 首页使用 Organization/LocalBusiness 信息；产品页使用 Product；文章页使用 Article；FAQ 使用 FAQPage（仅标记页面真实展示的问题和答案）。
- 建立面向问题的内容：选型、精度、量程、PLC/DCS/MES 对接、安装、校准、维护、行业应用。
- 每个关键结论提供参数、案例、更新时间、审核人或资料来源。
- 生成 `robots.txt`、`sitemap.xml` 和三语言 URL 集合。
- GEO 不依赖所谓“特殊 AI 标签”，核心是可抓取、结构清晰、原创、可验证、持续更新的工程内容。

## 验收标准

- 三种语言首页可通过独立 URL 直接访问。
- 语言切换保持当前页面，不返回首页。
- 三种语言页面均有独立标题、描述、canonical 和 hreflang。
- 关键导航无 404；联系和询价入口可见且可用。
- 移动端无固定宽度横向溢出。
- 页面包含 Organization、Product、BreadcrumbList 等与可见内容一致的 JSON-LD。
- 外部未知脚本不被加载。
