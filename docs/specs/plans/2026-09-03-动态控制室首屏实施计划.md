# 动态控制室首屏实施计划

> **给代理执行者：** 本计划按 TDD 的 RED-GREEN-REFACTOR 节奏执行。每个任务完成后运行对应测试；本项目当前目录不是 Git 仓库，因此不执行提交步骤。

**目标：** 将首页静态主视觉升级为三语言共用的动态工程控制流首屏，并提供移动端与减少动态降级。

**架构要点：** 模板输出语义化节点和 SVG 路径，CSS 负责入场、循环脉冲和响应式视觉，原生 JS 只在元素进入视口且用户未开启减少动态时添加运行状态。动态数据为视觉占位，不连接后端，不引入第三方库或外部资源。

**技术栈：** Node.js ESM、静态 HTML、CSS、原生 JavaScript；验证命令为 `node --test tests/*.test.mjs` 与 `node tools/build-site.mjs`。

**关联设计文档：** `docs/specs/2026-09-03-动态控制室首屏设计.md`

## 文件结构

- 修改：`site/src/template.mjs`——在首页 hero 视觉中输出四个本地化流程节点、SVG 路径和读数标记。
- 修改：`site/src/mettler.css`——增加动态面板布局、流程节点样式、SVG 动画、断点和减少动态规则。

- 生成：`site/assets/*`、`site/{zh-cn,en,ru}/index.html`——由构建命令同步源文件，不手工编辑。

### 任务 4：仅在可运行条件满足时启用循环

**涉及文件：**

- 修改：`site/src/app.mjs`

- [ ] **步骤 1：编写最小运行时逻辑**

在现有 reveal 初始化逻辑附近添加：

```js
const controlVisual = document.querySelector('.hero-control-visual');
const motionAllowed = !window.matchMedia('(prefers-reduced-motion: reduce)').matches;

if (controlVisual && motionAllowed && 'IntersectionObserver' in window) {
  const controlObserver = new IntersectionObserver((entries, observer) => {
    if (entries.some((entry) => entry.isIntersecting)) {
      controlVisual.classList.add('is-running');
      observer.disconnect();
    }
  }, { threshold: 0.2 });
  controlObserver.observe(controlVisual);
} else {
  controlVisual?.classList.add('is-static');
}
```

不要新增网络请求、随机数或定时器；动态读数只由 CSS 呈现。

运行：`node tools/build-site.mjs; node --test tests/*.test.mjs`

预期：构建输出包含 3 个 locale，测试全部通过；生成的 `site/assets/app.mjs` 与源文件一致。
